# Humanized Development Framework

## 1. UX & Visual Empathy
* Never use pure black (#000000) or default neon colors. Use organic, accessible color palettes.
* Implement human-centric spacing. Prioritize generous white space (padding/margins) to let elements breathe.
* Every UI transition must feel smooth and intentional—use cubic-bezier timing functions for animations rather than rigid linear transitions.

## 2. Copywriting & Communication
* Avoid generic placeholder text like "Lorem Ipsum" or robotic headlines ("Welcome to our site"). 
* Use storytelling-driven copywriting. Write in a conversational, second-person narrative ("You", "Your").

## 3. Code Quality
* Write clean, semantic HTML5. 
* Do not leave unstyled fallback containers. Every component must look intentional from day one.
